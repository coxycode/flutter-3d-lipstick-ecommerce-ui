# 🤝 Contributing to Rouvelle

Thank you for your interest in contributing to **Rouvelle**! We welcome community contributions, bug fixes, UI enhancements, and new platform adapters.

---

## 🌟 How Anyone Can Contribute

1. **Fork the Repository**: Fork this repo on GitHub to your account.
2. **Clone your fork**:
   `ash
   git clone https://github.com/your-username/rouvelle_app.git
   cd rouvelle_app
   `
3. **Create a Feature Branch**:
   `ash
   git checkout -b feature/amazing-feature
   `
4. **Make Your Changes**:
   - Write clean, idiomatic Flutter/Dart code.
   - Follow the existing design aesthetics (dark luxury, serif brand headers, rouge/champagne accents).
   - Ensure zero bloated dependencies.
5. **Test Your Changes**:
   `ash
   flutter analyze
   flutter test
   `
6. **Commit & Push**:
   `ash
   git commit -m " Add amazing new feature\
 git push origin feature/amazing-feature
 `
7. **Submit a Pull Request**: Open a PR describing your changes.
